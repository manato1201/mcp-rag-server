# 用語集

| 用語 | 意味 |
|---|---|
| **RAG** | Retrieval-Augmented Generation。質問のたびに、関連する文書の断片を検索して AI に渡し、回答を補強する方法 |
| **MCP** | Model Context Protocol。AI アプリ(ホスト)が、外のプログラム(サーバー)の道具を呼ぶ共通の約束 |
| **MCP ホスト** | MCP サーバーを起動し、道具を呼ぶ AI アプリ(例: Claude Desktop) |
| **道具(tool)** | MCP サーバーが公開する機能。`search`・`get_document_count` |
| **JSON-RPC 2.0** | 1 行 1 件の JSON で、呼び出しと結果をやり取りする形式。ここでは標準入出力で使う |
| **stdio** | 標準入出力(stdin / stdout)。MCP の通り道。**ログを書いてはいけない** |
| **チャンク** | 文書を分けた断片(既定 500 字・重なり 100 字) |
| **オーバーラップ** | 隣り合うチャンクの重なり。境界の前後の文脈を、片方に残す |
| **埋め込み(エンベディング)** | 文章を数の並び(ベクトル)にしたもの。意味が近いほど近い |
| **ベクトル検索** | クエリの埋め込みに近い断片を探す。意味で探せるが、型番に弱い |
| **コサイン類似度** | 2 つのベクトルの向きの近さ(0〜1)。ChromaDB は距離(`1 - 類似度`)を返す |
| **接頭辞(プレフィックス)** | e5 系で、質問(`query:`)・文書(`passage:`)の頭に付ける文字。学習時と同じ使い方が要る |
| **BM25** | 語の一致の点を、珍しさ・頭打ちの出現回数・長さの補正で付ける検索 |
| **トークン化** | 文を語に分けること。日本語は Sudachi |
| **SudachiPy** | 日本語の形態素解析器。助詞を除き、辞書形に直す |
| **辞書形** | 活用する前の形(「学び」→「学ぶ」) |
| **ハイブリッド検索** | ベクトルと BM25 を合わせる検索 |
| **RRF** | Reciprocal Rank Fusion。順位だけを使って、複数の検索結果を融合する(`1/(k + 順位)` の合計。k = 60) |
| **ChromaDB** | ローカルファイルに保存できるベクトルデータベース。コレクション = namespace |
| **namespace** | `SOURCE_DIR` の最初の階層のフォルダ名。ChromaDB のコレクション名になる |
| **差分インデックス** | 変わったファイル(ハッシュ・更新日時・サイズのどれかが違う)だけを処理する |
| **file_registry.json** | 差分の判断に使う、ファイルごとのハッシュ・更新日時・サイズの記録 |
| **markitdown** | PDF・Word・PowerPoint などを Markdown に変換するライブラリ |
| **watchdog** | ファイルの変更を監視するライブラリ。`auto_index.py` が使う |
| **デバウンス** | 連続した変更を、一定時間まとめて 1 回にすること |
| **frontmatter** | Markdown の先頭の `---` で囲んだ設定(`status`・`expires`) |
| **upsert** | あれば更新、無ければ追加。同じ `document_id` は上書きされる(古いチャンクは消えない) |
| **pickle** | Python のオブジェクトの保存形式。信頼できないファイルは、読んではいけない |
| **Recall@5** | 上位 5 件に、正解が入っている割合。検索の質を測る指標 |
