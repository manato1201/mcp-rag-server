# 講義資料: ローカルの RAG 検索サーバーを、基礎から作る

MCP RAG Server を題材に、**RAG・チャンク分割・埋め込み・BM25・RRF・MCP・運用・テスト**を、基礎から講義の形で学ぶ資料です。

## この講義の特徴

- **実際のコードを読む**。講義の引用は、ソースから**自動で**作っています(`python tools/quote_code.py docs`)。コードが変わると、テストが失敗して気づけます。
- **実行できる例には、実行結果が付く**。`# 実行できる` のコードは、テストが 2 回実行し、`# 出力` と一致するか確かめます(重いモデルは読み込みません)。
- **各回に確認問題と解答**。
- **正直に書く**。コードの食い違い・古いテスト・既知の問題も、そのまま書いてあります。
